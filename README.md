## 🚀 Quick Start

```bash
# Clone
git clone https://github.com/toolkitaiprompt-ui/AI-Prompt-Toolkit.git
cd AI-Prompt-Toolkit/artifacts/ai-prompt-toolkit

# Install
npm install

# Dev
npm run dev

# Build
npm run build

# Preview
npm run preview
```
